LedgerDirect for Magento 2 — release notes 1.3.2

Changes since 1.3.1:

- The payment page uses @ledger-direct/payment-ui 0.4.2 instead of 0.4.0, which fixes partial
  payments in the wallet flow: after a partial payment, a wallet button opens the payment for the
  rest instead of reloading the page again and again; an XRP payment whose amount changed while the
  wallet was connecting reloads instead of signing the old amount; a page that turned paid or
  expired meanwhile signs nothing; and an older status answer arriving late no longer turns the page
  back
- After payment the page goes to the order confirmation once. Clicking the button while the
  countdown ran out opened the success page twice; the second request, after Magento had cleared
  the checkout session, ended in the empty cart

Requires hardcastle/ledger-direct-core 0.12.0. Run bin/magento setup:upgrade after the update, and
in production mode bin/magento setup:static-content:deploy, so the new payment page script is
served.
