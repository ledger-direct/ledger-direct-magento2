LedgerDirect for Magento 2 — release notes 1.3.0

Changes since 1.2.8:

- The checkout offers only what the receiving account can take. A token the account cannot
  receive (no trust line, frozen, full) is not offered, so no order exists that nobody can pay. An
  account that is not activated yet keeps the native asset, and the configuration warns. When the
  node cannot be reached, tokens are left out and the native asset stays
- The XRPL and the Xahau configuration groups show what the saved receiving account lacks, read
  afresh on every visit
- Every text of the module in six languages: English, German, French, Dutch, Spanish and European
  Portuguese. French, Dutch, Spanish and Portuguese are new; German lacked the admin configuration,
  the logo options and parts of the email, English about 40 phrases
- The default payment method titles are translated per store view; a title the merchant set is
  shown as set. The title can be set per store view

Requires hardcastle/ledger-direct-core 0.12.0. Run bin/magento setup:upgrade after the update.
